怪物平衡檢查

這個檢查器是 Node 腳本，不再提供瀏覽器版資料載入。 平衡結果以資料庫原始數值為準，避免工具頁和腳本各自維護不同規則。

只檢查並輸出報告：

node scripts\MonsterBalanceCheck_v4.js --report-only

需要 JSON 輸出時執行：

node scripts\MonsterBalanceCheck_v4.js --json --report-only

確認要套用建議值時，指定 ID 寫回資料庫：

node scripts\MonsterBalanceCheck_v4.js --write --ids=slime,goblin
