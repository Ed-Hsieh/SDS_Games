# 跨章節故事大弧線

這份文件用來回答一個核心問題：第一章建立的東西，到了第二章、第三章是否有長大，而不是只在當下完成一個任務。

## 第一章定位

第一章不是沒有支線，而是「種子章」。

它的任務份量不應該像第二章、第三章那樣到處展開，否則玩家還沒理解世界就會被細節淹沒。第一章真正要做的是建立三件事：

1. 玩家與城鎮的關係：村長、書記、守衛、鐵匠、藥師不是按鈕，而是玩家回來會找的人。
2. 玩家與地圖的關係：南門外、城外道路、獵人棧道、腐根溪谷都應該是玩家逐步知道名字與風險的地方。
3. 玩家與災難的關係：史萊姆、銀絲、發黑樹皮、血月角鹿都只是地脈崩毀的早期症狀。

## 第一章支線分類

| 支線 | 敘事分類 | 作用 |
| --- | --- | --- |
| 鐵匠的煙囪 | 工藝成長 / 生存 / 感情 | 把鍛造從功能入口變成城鎮防線的一部分，後續接到秘銀、詞條、終局裝備。 |
| 藥師的空瓶 | 懸疑 / 生存 / 感情 | 把史萊姆異常轉成生活問題，後續接到毒霧、草藥短缺、荊棘女巫與難民照護。 |
| 南門守衛的靴底 | 感情 / 冒險 / 生存 | 把玩家走過的路變成城鎮巡守路線，後續接到公告欄、失蹤者、斷旗與城鎮最後防線。 |

第一章暫時不需要大型支線 BOSS。這是刻意保留，因為第一章的重點是讓玩家學會讀地圖、讀 NPC、讀線索。大型支線 BOSS 從第二章開始更合理，因為玩家已經知道這個世界不是只有主線怪物。

## 八條跨章節要素

### 地脈崩毀

第一章看到地方異常，第二章看到區域災害，第三章收束到古龍巢與魔王封印。

這是主線骨架。所有 BOSS 都應該是地脈斷裂後的不同後果，而不是各自獨立冒出來。

### 旅人手札與世界記憶

第一章由書記引導玩家記錄城外異常。第二章開始收納傳聞、謎題、地名與未確認線索。第三章變成決戰前的世界索引。

這條線能讓提示看起來像玩家自己的思考，而不是系統教學。

### 鍛造與裝備成長

第一章讓鐵匠與裝備變成求生工具。第二章加入副本圖紙、特殊素材、地形對策。第三章收束成終局裝備與套裝準備。

這條線要避免鍛造只是數值升級，而是玩家逐步準備面對更大災難的方式。

### 藥師與生存照護

第一章從空瓶和史萊姆凝膠開始。第二章接到毒霧、草藥、荊棘交易。第三章接到難民、最後一鍋湯、物資分配。

這條線讓城鎮有日常感，也讓災難不是只有戰鬥。

### 城鎮邊界與守望

第一章用守衛靴底把玩家探索過的路線回寫城鎮。第二章讓公告欄和失蹤者擴大邊界壓力。第三章用斷旗、點名與撤離呈現最後防線。

這條線是地圖與大廳不能分裂的關鍵。

### 灰色交易與賭場

第一章只露出乞丐、市集、灰色情報。第二章加入黑市、走私煤印、賭場獎池與假賠率。第三章讓末日籌碼與暗盤交易成為絕望的一部分。

這條線可以把商店與賭場從可有可無的功能，轉成情報、特殊交易與風險選擇。

### 首領痕跡與狩獵流程

第一章用銀鐮伏獵者教玩家「線索、地點、誘餌、伏擊」。第二章讓各 BOSS 有不同入口與推進方式。第三章把古龍與魔王做成所有痕跡的總結。

這條線能避免 BOSS 只是紅色圖標在地圖上等玩家撞。

### 副本機制與世界補完

第一章用幽暗洞窟呈現普通人被災難壓碎。第二章用叢林、遺跡、雪山補出毒素、辨識、鍛造詞條等玩法。第三章用煉獄深淵接到終局準備。

副本不應該只是地圖外的戰鬥關卡，而是世界觀和裝備路線的另一面。

## 後續使用方式

新增任務或支線時，先問它接在哪一條大弧線上。

如果接不上，代表它可能只是好玩的單點事件。單點事件可以存在，但比例不能太高，否則世界會散掉。
