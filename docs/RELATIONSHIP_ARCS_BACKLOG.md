# 主角與 NPC 牽絆線備忘

這份文件先記錄「主角和某些角色形成朋友、信任、牽絆」的方向。它暫時不進入實作，避免打斷目前的收斂工作。

## 核心判斷

目前遊戲已經有很多情感型支線，但大多是「NPC 自己的短篇故事」。

缺少的是玩家能逐步感受到的關係變化：

- NPC 一開始把主角當外來冒險者。
- 主角完成事件後，NPC 開始信任主角。
- NPC 願意透露更私人的事情。
- 後期 NPC 的語氣、委託內容、場所狀態因主角而改變。
- 終局時，玩家會記得這些人，而不是只記得任務獎勵。

## 不建議叫好感度

這不是戀愛或送禮系統。建議命名為：

- 信任階段
- 牽絆記錄
- 熟識記錄
- 同行記憶

暫定可用階段：

1. 陌生人
2. 託付者
3. 可信任的人
4. 同行者
5. 生死之交

## 適合優先發展的角色

| 角色 | 牽絆方向 | 最適合的情緒 |
| --- | --- | --- |
| 村長 | 從管理者到把城鎮託付給主角 | 沉重、信任、責任 |
| 書記 | 從記錄者到共同推理與保存名字的人 | 溫柔、固執、感人 |
| 鍛造師 | 從嘴硬工匠到把反擊順序交給主角的人 | 粗魯、可靠、遺憾 |
| 藥師蓮娜 | 從照護者到一起守住城鎮日常的人 | 溫柔、實務、悲憫 |
| 巷口流浪者 | 從灰色情報人到不明說的盟友 | 狡黠、諷刺、義氣 |
| 瑪洛 | 從貪婪賭場人到被迫站在玩家這邊 | 灰色、誘惑、救贖 |
| 芙蕾 | 從斷旗手到終局戰友情感線 | 克制、創傷、堅定 |
| 塔維 | 怕黑卻點燈的守燈人 | 溫柔、孤獨、守望 |

## 最感人路線候選

1. 書記的最後索引：不是墓誌銘，而是替活人保留名字。
2. 藥師的最後一鍋湯：藥水救傷口，熱湯讓人明天願意醒來。
3. 斷旗手芙蕾：撤退不是潰敗，點名不是形式。
4. 鍛造師與妮露：失蹤學徒留下的圖紙，把鍛造變成傳承。
5. 北境來信：普通人抱怨豆子太硬，比戰報更能證明世界曾經正常。

## 暫緩原因

這條系統很有價值，但會牽動：

- NPC 對話分支
- 任務回報優先權
- 城鎮場所狀態
- 旅人手札分頁
- 終局回顧或結局文字

因此應該等核心流程、UI、戰鬥、副本、事件池收斂後再做。
