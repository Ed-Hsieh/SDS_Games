# 內容重建矩陣

更新日期：2026-07-04

本文件把 1-70 等級怪物、裝備、素材、副本與圖片批次接在同一張執行表上。原則是：邏輯正確的系統只補內容；時間點或分類錯誤的內容先移除錯誤來源，再重新接入。

## 全域口徑

- 工藝系列：弱保底。每 5-10 級提供基本可用裝備，避免玩家空窗，但不承擔主要追求。
- 怪物掉落：主要追求。普通怪給核心素材與低機率特色裝備；菁英怪給流派核心或圖紙；Boss 給故事里程碑裝備或唯一素材。
- 副本：高風險高回報渠道。副本應提供專屬裝備、素材、圖紙與製作物，不是唯一 Boss 前準備。
- 賭場：資源轉化與抽獎追求渠道。強裝可以存在，但強度要跟章節曲線與可取得時點綁定。
- 套裝：主要體現在工藝之外，包含怪物、菁英、副本、Boss、塔與終局副本。
- 圖片：最後接入。等 ID、掉落、用途與階段定位穩定後，再批次生成怪物、裝備、素材與副本場景圖。
- 圖像方案：保留目前素材、武器、圖紙的暗色寫實風格；怪物改用分級版型重生，不採全資產洗版。細節見 `docs/ART_REGEN_PLAN.md`。
- 怪物版型：普通怪優先透明或極簡暗底；菁英與非主線 Boss 可有低調場景；主線 Boss 保留現行滿版大圖，不進一般批次覆蓋。

2. 掉落修正：`shadow_bat` 不再掉 `shadow_shard`，避免 Lv5-10 提早取得暗影前置。
3. 掉落修正：`lich` 不再掉 `shadow_shard`，維持它作為亡靈/暗晶/靈魂來源。
4. 微光前置：新增 `glimmer_shard`、`glimmer_focus`，並用 `attackSpeed` / `critChance` 做弱化版節奏效果，不使用正式 `light` 詞綴。

6. 圖片規格修正：先鎖定怪物分級版型；已生成但不符普通怪/菁英怪規格的怪物圖要列入重生隊列。
