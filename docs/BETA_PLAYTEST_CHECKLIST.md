# Beta 遊玩驗收清單

這份清單用來做每一輪「能不能真的玩」的手動驗收。資料檢查通過只能證明結構沒有斷，這份清單用來確認玩家操作、畫面節奏與回饋是否順。

## 驗收環境

- 桌面解析度優先使用 `1280x631`。
- 每次 UI 或流程改動後，至少跑一次大廳、冒險、戰鬥、結算、鍛造、商店、旅人手札。
- 若有新增副本、賭場或市集改動，額外驗收對應場景。

## 主流程路線

1. 進入大廳，確認右側動態不因打開手札、商店、鍛造而被刷新。
2. 與村長對話，確認任務狀態訊息進入右側動態，對話內容不重複貼成摘要。
3. 找書記接續第一章任務，確認委託與旅人手札可以理解下一步。
4. 進入冒險地圖，用 `WASD / 方向鍵` 移動，用 `F` 調查地點。
5. 完成一場普通戰鬥，用 `A` 攻擊、`D` 道具、`F` 撤退測一次冷卻與回饋。
6. 戰鬥勝利後確認結算直接進入面板，戰利品格子、金幣、經驗與背包轉移正常。
7. 回城回報任務，確認回報必須找對 NPC，旅人手札只提供指引。
8. 進鍛造，確認缺料、成功率、裝備數值與 hover 詳情一致。
9. 進商店或市集，確認購買後物品進背包，交易介面與右側行囊不跑版。
10. 觸發銀鐮伏獵者線索，確認 BOSS 不裸露成大地圖紅色圖標，最終觸發需正確誘餌與地點。

## 副本路線

1. 進入五個副本入口，確認風險、獎勵方向與通關解鎖說明清楚。
2. 副本戰鬥使用與冒險相同的 `A / D / F` 操作。
3. 副本背景、戰鬥框、戰利品、物品 hover 與冒險場景保持同一套視覺密度。
4. 通關後確認副本獎勵、圖紙保底、旅人手札紀錄與城鎮狀態有對應變化。

## 賭場路線

1. 進入賭場，確認籌碼與金幣轉換清楚，不出現兩套資源互相脫節。
2. 下注、抽獎或特殊交易後，確認獎池物品能進入背包或解鎖對應能力。
3. 抽到戰術技能時，確認技能只有在已解鎖條件成立後能裝備。
4. 賭場右側動態與大廳、市集一致，不出現獨立舊版版型。

## 暫緩項目

- 雙武器、副手與盾牌姿態不在本輪驗收內。若畫面或資料中出現入口，視為需要移除或隱藏。
- 新關係線、新支線 BOSS、新賭場遊戲與新大型場所不作為 Beta 阻塞。
