# 遊戲循環與素材收斂待辦

更新日期：2026-07-03

這份文件記錄「目前尚未完成、需要後續設計或實作」的遊戲循環內容。已完成的驗證與實作細節不放在這裡，避免清單膨脹。

## 目前結論

- 素材過剩問題尚未真正解決。
- 已完成的是防止未來繼續發散的第一步：建立系列裝備架構，讓同一素材群可以支撐多種武器型制。
- 現有素材仍需重新分類、盤點用途、刪除或轉移錯誤類型。
- 1-30 級內容已先用進度映射展開到 1-70，但中段內容還沒有真正填滿。

## P0：素材收斂

| 項目 | 目前狀態 | 下一步 |
| --- | --- | --- |
| 素材總量過多 | 目前素材約 94 種，仍混入代幣、任務物、前置道具、裝備殘片等非素材概念。 | 建立素材盤點表，將每個條目標成真素材 / 道具 / 代幣 / 任務物 / 裝備殘片 / 待刪除。 |
| 孤兒素材 | 部分素材沒有穩定取得途徑或沒有實際合成去向。 | 盤點「有來源無用途」、「有用途無來源」、「來源與用途都不清楚」三類。 |
| 素材定義不清 | 目前資料中有些可使用物、貨幣、紀念物被放進素材分類。 | 採用新定義：素材必須可用於合成成品、有穩定取得途徑、本身不可直接使用。 |
| 群落掉落 | 怪物群落素材邏輯大致可接受，例如骷髏掉骨頭、史萊姆掉凝膠。 | 保留 70% 已符合幻想的掉落，優先清理後期臨時新增的素材。 |
| 合成樹規劃 | 還沒有完整材料轉化成裝備、藥水、道具的架構。 | 先規劃「素材群 -> 系列裝備 / 特殊裝備 / 藥水 / 道具」的流向，再開始刪改。 |

## 後續開發原則

- 不再為每把武器新增一整套素材。
- 系列裝備作為保底戰鬥力，不做成最強追求。
- 特殊裝備與副本裝備負責吸引玩家刷怪和挑戰。
- 新增物品前先確認分類規格，不允許臨時塞入素材。
- 每 5-10 級提供一個合理裝備級距，鼓勵玩家強化現有裝備，而不是每級都換裝。
- 圖片風格必須接近現有暗色寫實奇幻風，不要突然變成過度華麗或不同遊戲的美術。
