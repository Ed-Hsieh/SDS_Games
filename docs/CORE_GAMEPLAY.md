# 核心玩法確認

## 一句話目標

玩家在冒險、副本與無盡塔中取得資源、裝備與任務進度，回到大廳整理戰利品，透過交易與鍛造強化角色，再挑戰更高風險的區域。

## 玩家體驗定位

這是一個以「短回合冒險、戰鬥節奏、裝備成長、任務推進」為核心的輕量 RPG。玩家每次進入遊戲都應該清楚知道下一步可以做什麼，並且在 3 到 8 分鐘內完成一次有回饋的行動循環。

## 核心循環

1. 選擇目標：從大廳確認目前任務、可挑戰區域與角色狀態。
2. 行前準備：整理背包、購買或出售物品、鍛造或調整裝備。
3. 進入挑戰：選擇冒險區域、副本或無盡塔樓層。
4. 戰鬥與事件：透過節奏攻擊、補給與風險判斷完成遭遇。
5. 結算收穫：獲得金幣、經驗、材料、裝備與任務進度。
6. 回到大廳：把新資源轉化為下一次挑戰的能力。

## 主要目標層級

短期目標：
- 完成目前追蹤的任務步驟。
- 在單場戰鬥中存活並取得戰利品。
- 收集足夠金幣、材料或消耗品。

中期目標：
- 製作、重鑄或替換裝備。
- 解鎖更高難度副本與無盡塔樓層。
- 建立一套穩定的補給與出售流程。

長期目標：
- 征服無盡塔。
- 清理主要副本線。
- 完成任務鏈並解鎖新的玩法或區域。
- 形成可辨識的角色構築方向。

## 任務融入方式

任務不能只是額外清單，必須成為玩家選擇下一步的引導。

任務應該在三個位置保持可見：
- 大廳：顯示目前推薦目標與下一個行動入口。
- 挑戰場景：顯示和目前區域相關的任務進度。
- 結算畫面：明確顯示本次行動推進了哪些任務。

任務獎勵應該優先推動核心循環：
- 金幣與材料讓玩家回到鍛造或商店。
- 裝備與消耗品讓玩家能挑戰更高風險。
- 區域或系統解鎖讓玩家有新的下一步。

## 穩定體驗原則

每個場景都要回答玩家三個問題：
- 我現在的目標是什麼？
- 我按下這個行動會得到什麼、承擔什麼風險？
- 完成或失敗後，我下一步要去哪裡？

每次遊玩都應該產生至少一種進度：
- 角色經驗或金幣增加。
- 任務進度增加。
- 背包材料或裝備增加。
- 區域、樓層或功能解鎖。

失敗不應該讓玩家卡住：
- 戰敗後要有明確恢復路徑。
- 懲罰要可理解且可承受。
- UI 必須提供返回、重試或整理資源的出口。

## 系統定位

大廳：
- 主要決策中心。
- 顯示任務目標、角色狀態、推薦入口與資源概況。

冒險：
- 基礎資源與任務推進區。
- 適合短時間戰鬥與收集。

副本：
- 有路線、樓層、事件與 Boss 的風險挑戰。
- 應該提供比冒險更好的材料與裝備機會。

無盡塔：
- 高壓戰鬥挑戰與長期目標。
- 強調節奏操作、連續勝利與樓層突破。

商店：
- 資源交換與補給整理。
- 買賣流程必須快速、清楚、不中斷遊戲節奏。

鍛造：
- 把材料與金幣轉化為成長。
- 應該讓玩家理解缺少什麼、成功後變強在哪裡。

## 操作收斂

冒險與副本先採用單武器、被動戰術技能與簡化鍵盤操作：

- 探索：`WASD / 方向鍵` 移動，`F` 調查，`J` 打開旅人手札，`I/B` 打開背包。
- 戰鬥：`A` 攻擊，`D` 使用道具，`F` 撤退。
- 雙武器、副手與盾牌姿態暫緩，不列入近期核心。這些設計會牽動戰鬥核心、裝備欄位、詞條平衡與 UI 版型，應等單武器戰鬥手感穩定後再獨立規劃。

## 近期開發優先順序

P0：完整存檔與讀檔
- 角色、背包、金幣、任務、無盡塔與副本進度要能穩定保存。

P1：旅人手札與委託思考提示
- 取消上方 HUD 型摘要。任務、BOSS 痕跡、缺料鍛造與裝備替換都應收進旅人手札、委託詳情或右側動態，讓玩家主動翻閱，而不是被畫面頂部直接告知下一步。
- 具體分類、事件連動與第一輪實作切片見：[LEDGER_AND_WORLD_EVENT_DESIGN.md](D:/TestProj/SDS_Games/docs/LEDGER_AND_WORLD_EVENT_DESIGN.md)。

P1：任務結算回饋
- 戰鬥、交易、鍛造與探索後要顯示推進了哪些任務。

P2：挑戰前風險說明
- 進入副本或無盡塔前顯示敵人強度、可能獎勵與建議準備。

P2：裝備與道具圖示資產表
- 等素材提供後，集中管理商店、背包、裝備、掉落與結算圖示。

## 穩定核心機制定義

當以下條件成立，就可以視為核心體驗穩定：

1. 玩家從大廳出發後，能在 5 分鐘內完成一次明確的挑戰或任務行動。
2. 每個主要場景都有一致的提示、確認、成功與失敗回饋。
3. 任何戰鬥或交易結束後，都有可見的下一步。
4. 任務不只是列表，而是能引導玩家進入對應玩法。
5. 角色成長、裝備成長與任務進度彼此互相支撐。
