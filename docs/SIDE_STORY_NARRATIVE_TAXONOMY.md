# 支線敘事分類與補肉方向

本文件用來整理第二、三章支線的敘事功能。它不取代 `QuestStories.js` 的遊戲文本，而是幫助判斷支線目前偏向感情、冒險、懸疑、陰謀、生存、世界觀補完或黑色幽默，避免所有支線都變成「接任務、打怪、回報」。

對應資料位於：

- `src/js/data/SideStoryNarrativeTaxonomy.js`
- `src/js/data/QuestStories.js` 的 `narrativeMeta`

## 分類定義

| 分類 | 功能 |
| --- | --- |
| 感情 | 讓玩家記得角色與普通人的處境，例如家書、失蹤者、撤退者。 |
| 懸疑 | 讓玩家追線索、聽傳聞、確認異常是否真實。 |
| 冒險 | 讓玩家透過地點、路線、危險區域完成探索。 |
| 陰謀 | 黑市、帳冊、賭場、貨號、走私路線。 |
| 黑色幽默 | 用灰色地帶、諷刺、荒謬感降低沉重感，但不破壞世界觀。 |
| 生存 | 避難、補給、城鎮防線、傷患、食物、路線安全。 |
| 世界觀補完 | 補主線沒有細講的歷史、地脈、遠古文明、怪物前因。 |
| 工藝成長 | 鍛造、圖紙、材料與裝備路線的故事化。 |
| 道德抉擇 | 角色必須承認真相、公開名單、回應無法送達的信。 |
| 隱藏奇遇 | 透過玩家行為觸發的非正式故事，例如暗桌、破產、死亡輪迴。 |

## 第三章分類

第三章目前感情與生存比例足夠，但缺少明確「終局支線 BOSS」作為高潮。建議後續優先把以下四條升級：

1. 斷旗手芙蕾 → 追旗魔將
2. 書記的最後索引 → 刪名者
3. 最後一夜的籌碼 / 暗桌契約 → 惡魔莊家
4. 沒有寄出的回信 → 熱痕幼龍或截信飛龍斥候

## 缺口判斷

目前支線不是沒有肉，而是肉還不夠「分層」。

- 第一章：生活感、城鎮入口、初學者引導足夠。
- 第二章：懸疑、陰謀、世界觀補完足夠；冒險事件與支線 BOSS 不足。
- 第三章：感情、生存、終局壓力足夠；需要 2 到 3 個有記憶點的人形或半人形支線 BOSS。

## 支線 BOSS 設計原則

不是每條支線都需要 BOSS。

- 單點支線：保留短篇味道，不硬塞戰鬥。
- 兩段支線：可以給菁英遭遇或特殊事件。
- 三段以上或牽涉城鎮狀態的支線：適合給專屬支線 BOSS。

## 後續補肉方向

短期先做文字與流程，不做圖片。

1. 先把每條第二、三章支線在旅人手札裡顯示分類。
2. 支線任務詳情顯示「這條線在講什麼」，不要只顯示物品與擊殺。
3. 先做 4 條支線 BOSS 流程設計，不急著產圖。
4. 地圖事件要依分類補足：懸疑支線給痕跡，感情支線給物件，陰謀支線給帳冊與暗號，生存支線給補給壓力。
## 第一章補充

第一章現在也納入支線敘事分類，但定位和第二、三章不同。

第一章是「種子章」：任務不追求大量展開，而是讓玩家第一次建立城鎮人物、地圖探索、線索記錄、鍛造與補給的關係。

| 支線 | 主要分類 | 次要分類 | 設計作用 |
| --- | --- | --- | --- |
| 鐵匠的煙囪 | 工藝成長 | 生存 / 感情 | 把鍛造與城鎮防線綁在一起，後續承接秘銀、詞條、終局裝備。 |
| 藥師的空瓶 | 懸疑 | 生存 / 感情 | 把史萊姆異常轉成生活問題，後續承接毒霧、草藥短缺、荊棘女巫與難民照護。 |
| 南門守衛的靴底 | 感情 | 冒險 / 生存 | 把玩家探索過的路線回寫成城鎮巡守路線，後續承接失蹤者、斷旗、最後防線。 |

第一章暫不配置大型支線 BOSS。它應該先教玩家讀地圖、讀 NPC、讀線索；第二章開始再把支線 BOSS 與更複雜的支線流程打開。

跨章節大弧線整理於 `docs/CROSS_CHAPTER_STORY_ARCS.md`。
