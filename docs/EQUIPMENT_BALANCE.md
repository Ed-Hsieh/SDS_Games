# 裝備成長與平衡規格

## 目標

裝備系統需要提供穩定的成長節奏，而不是每把武器、每個詞條、每個套裝各自獨立調整。後續調整應優先修改 `src/js/data/EquipmentBalance.js`，再讓裝備資料、鍛造、詞綴與套裝效果吃同一套規則。

## 等級分段

| 分段 | 等級 | 主要用途 | 預期稀有度 |
| --- | --- | --- | --- |
| 入門 | 1-4 | 新手武器、防具、初始掉落 | 普通、優秀 |
| 成長 | 5-9 | 第一輪替換與早期副本 | 優秀、稀有 |
| 熟練 | 10-14 | 中期副本與無盡塔壓力層 | 稀有、史詩 |
| 英雄 | 15-22 | Boss 裝備、套裝核心件 | 史詩、傳說 |
| 終局 | 23-30 | 長期目標與高階套裝 | 史詩、傳說 |

## 稀有度定位

| 稀有度 | 強度倍率 | 詞條數 | 定位 |
| --- | ---: | --- | --- |
| 普通 | 1.00 | 0-1 | 基礎裝備，主要用於過渡 |
| 優秀 | 1.18 | 1-2 | 初期可用裝，開始出現明確方向 |
| 稀有 | 1.42 | 1-3 | 中期主力，詞條組合開始影響打法 |
| 史詩 | 1.72 | 2-4 | 玩法核心裝，通常帶有特殊效果 |
| 傳說 | 2.12 | 3-5 | 長期追求，應搭配套裝或特殊機制 |

## 武器分布

武器攻擊力現在有統一建議區間，資料庫中的實際武器仍可因攻速、暴擊、吸血、元素或套裝價值偏離一點，但偏離時應該有理由。

| 分段 | 建議攻擊區間 |
| --- | ---: |
| 入門 | 4-13 |
| 成長 | 12-24 |
| 熟練 | 22-36 |
| 英雄 | 34-58 |
| 終局 | 54-82 |

## 鍛造詞條規則

鍛造與洗鍊現在使用同一份稀有度設定：

- 裝備稀有度決定詞條數量。
- 裝備稀有度決定可骰出的詞條稀有度權重。
- 詞條加成欄位集中由 `AFFIX_STAT_KEYS` 管理，避免出現 `undefined` 詞條鍵。
- `equipment` 類型會正規化為 `armor`，避免防具配方骰不到防具詞條。

## 套裝規則

套裝資料統一以 `src/js/data/Equipment.js` 的 `SetDatabase` 為準。`EnhancementManager` 不再維護第二份套裝清單。

目前已接入角色戰鬥屬性的套裝效果：

- 攻擊百分比與固定攻擊
- 防禦百分比與固定防禦
- 暴擊率、暴擊傷害
- 攻擊速度
- 吸血
- 傷害減免
- 穿甲
- 全屬性百分比

仍屬於後續要接入戰鬥判定的效果：

- 指定種族增傷
- 元素增傷與元素抗性
- 復活旗標
- 虛空狀態機率
- 經驗、金幣、掉落加成

## 下一步

下一階段建議做「裝備平衡檢查工具」，輸出每件裝備的等級、稀有度、實際強度分數與建議區間。這樣調整武器與 Boss 掉落時，可以直接看到哪一件超標或過弱。
