# 支線重寫第二輪紀錄

本輪目標是把支線從「功能型委託」改成「人物短篇」，並依照章節增量規則分配內容。第一章維持入門與城鎮日常，不把所有新人物與事件塞進第一章；第二章開始讓支線補足地脈崩毀造成的社會後果；第三章則讓支線回收終局壓迫、避難、裝備準備與城鎮記憶。

完整支線故事、角色去向與場景分配請以 [SIDE_STORY_STORY_BIBLE.md](D:/TestProj/SDS_Games/docs/SIDE_STORY_STORY_BIBLE.md) 為準。本檔只保留本輪改動摘要與實作對應。

## 設計注意

- 第一章不再追加大型支線，只保留玩家認識城鎮、NPC、基礎系統的短篇。
- 第二章支線負責把主線沒空說的地脈後果擴散到工匠、賭場、黑市、海岸與紀錄工作。
- 第三章支線負責把終局壓迫落到城門、避難補給、裝備路線與活人名冊。
- 新角色不一定需要成為可點 NPC；可以透過圖紙、帳冊、燈號、旗幟、索引存在，避免大廳過度膨脹。
