# 遊戲收斂計畫

目前遊戲已經具備收斂完成的機會，但前提是進入「封核心、補缺口、只修必要擴充」階段。

如果繼續同時擴張 UI、故事、BOSS、支線、賭場、圖片、裝備、事件，專案會一直變大但不會變完整。

## 收斂目標

把遊戲收成一個可完整遊玩的版本：

1. 玩家進入城鎮。
2. 透過 NPC 與城鎮事件理解目標。
3. 前往地圖探索。
4. 遭遇怪物、事件、線索與 BOSS 流程。
5. 取得素材、裝備、圖紙、金幣與情報。
6. 回到城鎮回報，城鎮狀態改變。
7. 推進三章主線，最後進入古龍與魔王終局。

## Beta 收斂原則

Beta 階段優先收斂「共通協作系統」，而不是把所有獨立內容都做完。

共通協作系統指的是：其他玩法、劇情、支線、BOSS、副本、商店、賭場、圖像與 UI 都會依賴的底層流程。這些系統穩定後，獨立內容才能在上面延伸，而不會每新增一個功能就重新拆一次架構。

Beta 前應優先完成：

- 任務、對話、回報、城鎮狀態的共通流程。
- 旅人手札、首領痕跡、世界見聞、鍛造備忘的共通記錄方式。
- 世界地圖事件、地點池、觸發條件、完成狀態的共通規則。
- 戰鬥核心、戰鬥 UI、戰利品結算、裝備效果的共通規則。
- 物品、裝備、圖紙、稀有度、tooltip、詳情彈窗的共通顯示規格。
- 商店、賭場、特殊交易、情報交易可以共用的交換與獎勵流程。
- 1280x631 的主要畫面驗收基準。
- 圖像資產映射、裁切、缺圖檢查、舊圖清理流程。

Beta 前可以暫緩：

- 依靠上述系統延伸的新支線。
- 新一批支線 BOSS。
- 牽絆系統的完整 UI 與演出。
- 第三章終局分歧。
- 新城鎮區域或大型場所擴充。
- 新賭場遊戲。
- 新裝備系列與新套裝。
- 雙武器、副手與盾牌姿態。
- 大量新增美術，而不是補缺圖。

判斷標準很簡單：如果一個項目會讓多個系統更穩，它屬於 Beta 收斂；如果它只是多一段內容、多一個玩法、多一個角色，它可以暫緩。

## 必須收斂的 9 個區塊

### 1. 主循環

城鎮、任務、地圖、戰鬥、掉落、鍛造、回報、城鎮變化必須串成一條穩定循環。

優先標準：玩家不看開發者說明，也知道現在可以去哪裡、為什麼去、回來找誰。

### 2. 章節與支線節奏

第一章作為種子章，第二章展開，第三章收束。支線不再用數量膨脹，而是補足角色、世界變化與主線沒有細講的部分。

優先標準：每章都有明確的情緒與玩法功能，不再只是更多任務。

### 3. 地圖與事件池

地圖要固定成可設計的世界，不再依賴無意義隨機。事件仍可隨機，但必須依地點池、章節、狀態與已完成事件控制。

優先標準：玩家期待事件，且不會一直看到重複公告欄、拓印或已完成事件。

### 4. BOSS 與線索

BOSS 不應裸露成紅色圖標。線索、地點、道具、誘餌、交易、解謎、伏擊都要能導向各自的 BOSS 流程。

優先標準：每個 BOSS 都有合理入口、推進方式與最終觸發，不會卡住或提早暴露。

### 5. 戰鬥與副本

世界戰鬥、副本戰鬥、BOSS 戰鬥要共用核心與共用 UI。副本要有獨特機制、風險說明與獎勵定位。

優先標準：玩家進副本時不會覺得切到另一個遊戲。

### 6. 裝備、圖紙、鍛造

裝備效果解析器、稀有度、套裝、圖紙來源、怪物掉落、鍛造材料要統一。鍛造不再只是做裝備，而是面對地形與 BOSS 的準備。

優先標準：玩家能理解某件裝備從哪裡來、為什麼要做、對哪種威脅有幫助。

### 7. 經濟、商店、賭場

商店要承接補給、情報、特殊交易與任務材料。賭場要從小遊戲收斂成灰色情報與高風險獎池，不再只是金幣交換。

優先標準：商店和賭場在流程內有自然位置，但不強迫所有玩家使用。

### 8. UI 與 1280x631 驗收

所有主要畫面以 1280x631 為最低桌面驗收標準。大廳、市集、場所、背包、倉庫、商店、鍛造、百科、戰鬥、戰利品都要保持同一套資訊密度。

優先標準：不跑版、不重疊、不出現忽大忽小的舊 UI。

### 9. 圖像資產

圖片已經大幅重製，後續應停止大批量生成，只做缺圖補齊、映射修正、裁切驗證、舊資產清理。

優先標準：所有正式使用的怪物、物品、圖紙、NPC、地點都有一致風格圖像，且沒有歪切圖。

## 暫緩項目

以下項目很有價值，但不應在收斂前繼續擴張：

- 主角與 NPC 牽絆系統
- 第三章終局分歧
- 新大型城鎮系統
- 新職業或主動技能系統
- 雙武器、副手與盾牌姿態
- 新一批大型支線 BOSS 美術
- 手機版 UI

## 收斂完成機率

目前有機會收斂完成。

原因：

- 主線三章已有骨架。
- BOSS 流程已有資料結構。
- 支線分類與跨章節弧線已建立。
- 戰鬥、裝備、鍛造、百科、旅人手札都有基礎。
- 圖像資產已進入替換與清理階段。
- 已有多個資料一致性檢查腳本。

最大風險不是做不到，而是繼續開新口。

## 建議收斂順序

1. 鎖定主循環，完整跑通第一章到終局。
2. 修地圖事件池與 BOSS 線索卡點。
3. 統一戰鬥、副本、戰利品、鍛造與商店 UI。
4. 補第二、三章支線文案節奏，但不新增大型系統。
5. 做裝備與經濟平衡檢查。
6. 做 1280x631 全畫面驗收。
7. 做圖像映射與舊資產清理。
8. 最後再回來考慮牽絆系統與終局分歧。
