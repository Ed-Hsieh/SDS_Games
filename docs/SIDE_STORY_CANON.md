# 支線故事正史

這份文件用來保存支線的故事核心。支線先從人物與故事出發，再拆成任務流程、獎勵、地圖觸發與城鎮狀態。

## 寫作原則

- 支線長短不是設計目標。故事需要多長才動人，就給它合理的篇幅。
- 任務流程要服務故事，不用為了湊步驟硬拉長。
- 支線可以搞笑、溫馨、荒謬或感人，但不能提前說完主線真相。
- 每條支線都要讓玩家記得一個人、一個小麻煩或一個選擇，而不是只記得獎勵。
- 目標仍要清楚。玩家可以不知道真相，但要知道下一步去哪裡、找誰、帶回什麼。
- 支線不能隨時裸露。每條支線都必須有觸發因果，可能是主線進度、地點探索、道具交付、NPC 回報或城鎮狀態。
- 支線裡誕生的新角色不一定要做成可點 NPC。只要他的出場已由前置事件控制，他就可以作為事件人物、書信人物、被提及的人或城鎮狀態存在。

## 第一章：邊境的悲鳴

第一章支線要讓玩家理解：城鎮不是 UI 大廳，而是一群正在勉強維持日常的人。

### 鐵匠的煙囪

鍛造師最近不敢把爐火開大。每次火舌碰到煙囪內壁，白煙就會倒灌進鋪子，像有什麼東西在上面咳嗽。

他嘴上說只是煙道老了，手卻一直按著桌角那枚被切斷的誘餌鉤。銀絲伏道的怪物讓他想起很久以前一次失敗的修繕：他把一個年輕獵人的鉤索修得太輕，獵人再也沒有回來。從那以後，他對「差不多能用」這句話有一種近乎粗暴的厭惡。

這次他不是想研究新技術，只是想把爐子修到能穩穩吞下礦石。鐵匠鋪亮起來，不是因為英雄需要強化，而是因為城鎮需要有人在夜裡還敢敲鐵。

流程拆解：

- 觸發：主線推進到鍛造師看過斷裂誘餌鉤後。
- 目標：帶回鐵礦石，協助鍛造師校準爐火。
- 回報：找鍛造師。
- 狀態：`town.blacksmith.forge_open`
- 獎勵定位：少量金幣經驗，並讓鍛造鋪成為故事上的戰力核心。

### 藥師的空瓶

藥師的架子上擺著一排空瓶，每個瓶口都被史萊姆凝膠腐蝕得滑亮。她把瓶子排得很整齊，像在替失敗的藥方舉行葬禮。

她不怕史萊姆，也不討厭黏液。真正讓她焦躁的是凝膠味道變了，原本應該像雨後青苔，現在卻帶著一點甜味。她說這不是好事，因為自然界裡「甜甜的危險」通常都很擅長把人騙近一點。

她需要更多凝膠樣本，不是為了開商店，而是為了確認農田土壤是否開始被地脈異常滲透。她會吐槽史萊姆像不會走路的果醬，但她其實在怕：如果藥水跟不上，城鎮會先從傷口感染開始崩壞。

流程拆解：

- 觸發：完成史萊姆主線後。
- 目標：帶回史萊姆凝膠。
- 回報：找藥師。
- 狀態：`town.apothecary.stock_basic_potion`
- 獎勵定位：小型生命藥水、少量金幣經驗、藥師台詞變化。

### 南門守衛的靴底

南門守衛沒有出現在公告欄上，因為他覺得自己的問題不夠英雄。他只是把靴子放在門邊，鞋底沾滿乾掉的黏液與碎草。

村長說那雙靴子已經修過三次，第四次再裂，守衛就得赤腳站崗。這聽起來很滑稽，但南門外路線重新標記後，第一個要走那些路的人不是冒險者，而是每天替城鎮確認風向、痕跡與腳印的守衛。

這條支線不是拯救世界，只是讓一個人明天還能站在門口。玩家帶回獸皮修補靴底後，南門提示會變得更可信，因為有人真的走過那些路。

流程拆解：

- 觸發：完成南門外近郊路線確認後。
- 目標：帶回獸皮修補守衛靴底。
- 回報：找村長。
- 狀態：`town.south_gate.guard_route_ready`
- 獎勵定位：少量金幣經驗，南門敘事狀態改善。

## 第二章：丘陵的執念

第二章支線要比第一章更分散，因為地脈崩毀已經讓每個人用自己的方式失控。

### 採藥籃不會說謊

藥師收到一只自己回來的採藥籃。籃子空了，提把上卻整齊綁著一截荊棘，像有人替它繫上緞帶。

採藥人沒有回來。村民說女巫會用荊棘交換珠跟人交易，拿走草藥，留下價格。藥師不相信籃子會自己走路，但她也不敢假裝這只是惡作劇。最可怕的不是女巫索價，而是村民開始覺得「也許照規矩交易就沒事」。

玩家要去找到籃子消失的林地，帶回能辨認毒霧變化的腺體或草藥痕跡。支線完成後，藥師會明白女巫不是亂抓人，而是在用失控的交易規則重建她失去的溫室。

流程拆解：

- 觸發：荊棘女巫線開啟後。
- 目標：調查毒霧林地，帶回毒腺樣本。
- 回報：找藥師。
- 狀態：`town.apothecary.understands_thorn_trade`
- 獎勵定位：毒素減免相關線索或材料，荊棘交換珠提示。

### 墓園書籤

書記在舊檔案裡找到一張書籤，上面寫著一個古代學者的名字。名字旁邊有一行小字：「若我還在尋找法杖，請不要把我只記成怪物。」

巫妖在主線裡是威脅，但這條支線讓玩家看見牠曾經是某個很會做筆記、也很怕忘記自己的人。書記不想替亡靈開脫，他只是害怕自己有一天也會把所有恐懼寫成冰冷分類，然後忘記每一條分類背後都有人。

玩家從古墓附近帶回骨片與拓印，書記會把巫妖的線索從「暴動源頭」改寫成「失去安魂法器的古代學者」。這不會阻止戰鬥，但會讓戰鬥多一層重量。

流程拆解：

- 觸發：巫妖線開啟後。
- 目標：擊退墓道亡靈或帶回骨片。
- 回報：找書記。
- 狀態：`town.scholar.records_lich_name`
- 獎勵定位：亡靈圖紙提示、古代符文材料、書記台詞變化。

### 沉鐘下的失眠人

城鎮有人連續幾夜聽見鐘聲。起初大家只當他失眠，直到書記把他敲在桌上的節奏和沉鐘海岸紀錄排在一起，發現兩者吻合得太乾淨。

這條支線讓沉鐘神諭不只存在於海岸，而是透過地脈回到城鎮。主線不需要花篇幅解釋每個居民如何受影響，但支線可以讓玩家看見：災難靠近時，第一個被打擾的可能不是城牆，而是一個睡不著的人。

流程拆解：

- 觸發：沉鐘神諭主線進行中。
- 目標：擊退沉鐘異響附近的幽魂，帶回回聲殘留。
- 回報：找書記。
- 狀態：`town.scholar.records_drowned_bell_rhythm`
- 獎勵定位：沉鐘神諭節奏提示、冰霜/古代符文材料、書記推理台詞變化。

### 帳冊上的名字

村長手上有一份失蹤工匠名單，紙角被摺得很平，像有人每天都想貼出去，又每天收回抽屜。灰燼男爵的帳冊讓這些名字不再只是謠言。

這條支線讓灰燼男爵的暴政先以「人不見了」的方式壓到城鎮，而不是只等玩家到要塞才知道他很壞。村長必須做出選擇：維持城鎮表面安定，還是把名字釘上公告欄，讓難過變成誠實。

流程拆解：

- 觸發：灰燼男爵主線進行中。
- 目標：擊退黑鐵倉道附近的影兵，帶回影徽。
- 回報：找村長。
- 狀態：`town.notice_board.missing_workers_named`
- 獎勵定位：黑鐵材料、要塞線索、公告欄狀態變化。

## 第三章：諸神黃昏

第三章支線要讓玩家感覺終局不只是 BOSS 靠近，而是每個小人物都在決定自己要如何迎接明天。

### 北境來信

信使倒在城門口，懷裡的信已經被熱風烤到捲邊。信不是軍情，也不是求援，而是一封寫給母親的普通家書。內容反覆提到北境的天空變紅，但最後一段卻在抱怨軍糧裡的豆子太硬。

玩家可以把信交給村長、書記，或留到找到收信人線索後再歸檔。這條支線不提供主線答案，只讓玩家知道北方不是地圖上的高階區，而是有人生活過、寫信過、甚至抱怨豆子過的地方。

流程拆解：

- 觸發：北方邊境開啟後。
- 目標：取得北境焦邊信，交給合適 NPC 歸檔。
- 狀態：`town.refugees.northern_letters`
- 獎勵定位：北境熱痕線索、故事收藏。

### 最後一鍋湯

深淵裂口開啟後，城鎮廚房開始收留避難者。掌廚人說他不懂地脈、古龍或魔王，但他知道人餓了會先吵架，吵架會讓守衛分心，守衛分心就會讓怪物進門。

玩家收集安全食材或保護補給路線後，城鎮動態會從恐慌多一點日常。這不是史詩，但它能讓玩家感覺自己守住的不只是世界，而是能在明天早上喝到熱湯的人。

流程拆解：

- 觸發：深淵裂口開啟後。
- 目標：收集安全食材或保護補給路線。
- 狀態：`town.refugees.soup_kitchen_warm`
- 獎勵定位：小型恢復品、城鎮溫馨狀態、終局前情緒緩衝。
