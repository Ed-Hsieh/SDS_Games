# Game Design Guide

更新日期：2026-07-03

這份文件整理現行玩法規格；後續系統設計以這裡為準。

## 核心循環

玩家體驗要圍繞：

探索 -> 採集與掉落 -> 裝備構築與鍛造 -> 挑戰 BOSS -> 解鎖新階層

任務可以提供方向與故事，但不能把素材、經驗、裝備全都直接餵給玩家。玩家應該需要透過戰鬥、掉落、製作、修復與副本來補足戰力。

## 難度曲線

- 前期：白手起家，主要挑戰是活下去。裝備能用就好，耐久壓力要明顯，拳頭與低階武器都會參與戰鬥。
- 中期：開始撞牆，主要卡點是 BOSS。玩家需要在乎裝備品質、詞綴、修復與套裝，不應該全靠任務獎勵通關。
- 後期：精英怪與 BOSS 要要求傳說裝備、合理配置與流派理解。材料取得途徑會變多，農怪壓力降低，挑戰重心轉到 BOSS 與構築。
- 等級不能靠幾隻低階怪快速推進。主線經驗應略低於 BOSS 需求，讓玩家自然觸發支線、練等或製作。

## 探索與疲勞

- 疲勞初始值為 20，每級最大值 +10。
- 疲勞耗盡後進入虛弱 DEBUFF，全部屬性降低 20%。
- 玩家死亡會被送回家，死亡懲罰規則待定。
- 探險要消耗資源，但不要使用金幣作為主要成本，避免玩家因為沒錢進入死局。
- 大廳每秒回復 1 點疲勞。後續可用金幣、跑腿任務或其他服務恢復，但不能形成死局。
- 地圖未探索區域維持黑幕；探索過的區域正常點亮，不做暗色輪廓。
- DEV 模式要打開地圖，方便測試。

## 背包與倉庫

- 背包的作用是限制玩家野外拿取物品，避免大量刷取素材。
- 倉庫是長期儲存，不應與背包混淆。
- 冒險地圖中不能直接與倉庫互動，這是正確限制。
- 背包擴充應透過鐵匠鋪打造或委託市集取得，不放在背包介面內干擾主要操作。
- 擴充說明應靠教學、鐵匠入口、委託提示或需求不足提示呈現。

## 裝備與掉落

- 前期武器或裝備約 10 到 20 下之間會壞，讓玩家願意收集素材、製作、修復或刷怪拿寶物。
- 前期不要直接發給玩家額外武器或裝備；第一個主線任務已給予生鏽短劍。
- 等級 1 史萊姆、等級 2 哥布林等低階怪可以掉落裝備，支撐玩家早期農裝。
- 任務獎勵素材要克制，避免玩家不需要打怪就完成鍛造與修復。
- 裝備稀有度主要跟詞綴與品質走；不能讓非裝備道具混入裝備欄位。

## 戰鬥面板與雙武器

- 戰鬥不暫停，也不以戰鬥紀錄作為主要資訊呈現。
- 裝備效果、套裝效果、BUFF、DEBUFF 要在非戰鬥介面先建立認知，戰鬥中只顯示精簡狀態。
- 武器卡需要顯示能力 icon、觸發條件與數值描述，避免玩家進戰鬥後才第一次看到效果。
- 戰鬥節奏條採圓形節奏環，主手與副手拆成兩個區塊。
- 副手武器只在主手攻擊後取得攻擊窗口。
- 副手窗口為兩圈，降低操作難度。
- 副手成功攻擊後該武器進入自己的冷卻；如果玩家沒有攻擊而錯過窗口，不進入冷卻，支援下一輪主手後再嘗試。
- 雙武器的主要代價是失去防具欄位與操作負擔，不再額外加入刻意數值懲罰。

## 元素與狀態

- `poison` 改成累積毒素。毒素不計算防禦，會在怪物血量條底部累積；當普通傷害加累積毒素達到怪物剩餘生命時直接處決。
- `voidDamage` 改成 `void`。
- 虛空效果定位為吞噬：每秒造成 X 點虛空屬性傷害，造成傷害時回復生命。
- `enhanceBonus`、`retreatCostReduction`、`coldImmune`、`eliteDamageReduction` 不屬於現行裝備設計，應移除或改成其他系統。

## 鍛造與強化

- 鍛造製作目前可作為資訊密度參考。
- 強化、修復、詞綴重鑄要用清楚的三欄或分區流程：選擇裝備、結果預覽、材料與費用。
- 強化文案使用「保護」取代「穩定度」。
- 不再顯示「印記」作為獨立名詞。突破提示只在鍛造時說明可能獲得能力。
- 強化只揭露下一階段可能獲得的能力，不一次攤開全部階段。
- +10 原本應非常困難，突破上限物品不能直接破壞這個設計。賭場突破上限道具傾向改為避免強化耐久下降或保護消耗。
- 元素培養流派暫緩，避免和既有強力元素、傳說裝備與詞綴平衡互相衝突。

## 百科與資料分類

百科五大分類為裝備、素材、圖紙、物品、怪物。

每個分類都要有自己的資料規格與呈現方式：

- 裝備：顯示戰鬥數值、稀有度、等級、詞綴、套裝與特殊效果。
- 素材：顯示用途、來源怪物或地點；來源可快速連結百科，未知來源顯示問號。
- 圖紙：顯示成品 icon、需求與去向；成品詳細可用 hover 或快速連結查看。
- 物品：顯示用途、來源、消耗方式或成就關聯；不應出現攻擊力、防禦力等裝備數值，除非它本質就是裝備。
- 怪物：顯示等級、棲息地、掉落物、可施加的 BUFF / DEBUFF、首領或菁英標記；掉落物與素材要能快速連結回對應百科條目。

每個分類都應具備流水號作為預設排序依據。排序可以依等級、章節進度、稀有度切換，並提供正倒序箭頭。

## 副本與賭場

- 副本目前吸引力不足，後續必須放進章節循環，而不是可有可無。
- 副本應提供特殊素材、圖紙、裝備、故事補完或 BOSS 前準備價值。
- 賭場不能產出與世界無關的孤兒物品。特殊道具要能接到成就、鍛造、收藏或經濟系統。
- 賭場道具如 `master_hammer`、`loaded_dice`、`craftsman_gouge`、`dungeon_master_badge` 不應分類為裝備。

## 驗證

- UI 主要驗收尺寸：`1280x631`。
- 平衡調整後要重新跑早期流程模擬，檢查裝備空窗、修復壓力、素材取得、藥水消耗與死亡率。
- 新裝備或新詞綴加入前，要檢查是否出現未設計 stats、百科分類錯誤、掉落來源缺漏或 UI 爆版。
