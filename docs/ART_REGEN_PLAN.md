# 圖像重生規格與隊列

更新日期：2026-07-04

目前採用方案：保留已經合適的暗色寫實風格，重生版型不符合系統用途的怪物圖。暫不採用「全部圖片替換」，除非後續確認舊版 UI 與新資產風格完全無法整合。

## 判斷原則

- 素材、武器、圖紙目前風格可保留，後續只補缺口與少量修正。
- 主線 BOSS 現行滿版大圖風格保留；不要在批次生成時覆蓋主線 Boss。
- 普通怪不應做成主線 Boss 式滿版展示圖；優先透明背景或極簡暗底。
- 菁英怪與非主線 Boss 可以有場景粉飾，但華麗度必須低於主線 Boss。
- 所有怪物圖仍維持目前暗色、寫實、低飽和、非卡通的世界觀。
- 生成前先確認資料定位：`normal`、`elite`、`boss`、`world_boss` 還要再分主線 / 支線 / 副本 / 塔。

## 版型模板

| 分級 | 建議輸出 | 生成提示重點 | 禁止事項 |
| --- | --- | --- | --- |
| 普通怪 | 512x512 WebP，RGBA 優先。 | 單一怪物本體，輪廓清楚，暗色寫實，透明背景或極簡煙霧底。 | 不要完整場景、不要史詩光束、不要像 Boss 海報。 |
| 菁英怪 | 512x512 WebP。 | 怪物本體佔主體，可加入少量地面、符文、低光環境。 | 不要滿版故事場面，不要壓過主線 Boss。 |
| 支線 / 副本 Boss | 512x512 WebP，必要時另做滿版場景圖。 | 有事件感與地點暗示，但構圖仍服務戰鬥卡。 | 不要用主線 Boss 的終局級華麗度。 |
| 主線 Boss | 保留既有滿版大圖；如需重生，單獨審稿。 | 完整背景、強烈壓迫、章節記憶點。 | 不要批次覆蓋。 |
