# 賭場與副本重構規格

這份文件整理目前 7 到 9 項未完成工作的正式方向：圖像資產整合、副本背景素材、賭場玩法與素材。重點不是先把圖片塞滿，而是先確定玩法、故事、素材與 UI 要往同一個方向長。

## 核心原則

- 美術遵守現有暗黑奇幻與資訊密集 UI 風格，不另開一套像新遊戲的視覺語言。
- 圖片是用來強化場景與閱讀，不可以讓 UI 變得難辨識、過度炫光或干擾互動。
- 賭場不能只是金幣小遊戲，它要成為補給、情報、特殊交易、隨機獎池與灰色故事的節點。
- 副本不能像另一個系統。入口、戰鬥、狀態、裝備 hover、戰利品結算、任務推進都要和世界地圖維持同一套操作感。
- 1280x631 是正式桌面驗收尺寸。新增賭場與副本 UI 時都要優先用這個高度檢查。

## 副本整合驗收

副本目前有故事、路由與獎勵定位，但使用體驗需要重新驗收。正式製作背景圖之前，先用下列項目檢查它沒有脫離世界地圖玩法。

### 戰鬥一致性

- 使用共用戰鬥核心與共用戰鬥 UI。
- 攻擊、道具、撤退按鈕的冷卻樣式與世界遭遇一致。
- 怪物生命、玩家生命、傷害跳字、爆擊、閃避、格擋、DOT、擊殺回饋一致。
- Buff / Debuff 圖示、倒數與特殊怪物外框一致。
- 裝備效果、詞條與戰術技能在副本戰鬥中和野外戰鬥同樣生效。

### 互動一致性

- 副本入口要使用和世界地圖相同語氣的風險提示：風險、獎勵方向、推薦準備。
- 副本內拾取、特殊事件與結算要進入右側動態或旅人手札，不只是一段系統文字。
- 裝備、道具、圖紙、材料都使用共用 hover 與詳情彈窗。
- 戰鬥結束後使用同一套 5 欄戰利品格子與收集流程。
- 失敗、撤退、死亡懲罰要和世界地圖一致，除非副本明確有特殊規則。

### 五個副本背景方向

| 副本 | 影像定位 | 背景重點 | UI 注意 |
| --- | --- | --- | --- |
| 幽暗洞窟 | 凡人的終點 | 地脈裂痕、礦道塌方、礦工遺骸、遠處岩石巨人陰影 | 中央路徑清楚，暗部不可吃掉按鈕與文字 |
| 迷霧叢林 | 蛛絲的遺贈 | 毒霧、廢棄編織村、蛛網、燃盡織機、九頭蛇陰影 | 綠霧要有層次，但不能讓稀有度綠色外框失真 |
| 遠古遺跡 | 盲目的秩序 | 黃金地宮、壓力板、齒輪防衛、奧術核心 | 金色不可過亮，避免和傳說稀有度外框混淆 |
| 冰封雪峰 | 熄滅的聖火 | 冰封山脊、寒冬鐵砧、被雪埋住的鍛造痕跡 | 不新增特殊鍛造入口，只呈現現有鍛造升級的來源 |
| 煉獄深淵 | 絕望的火種 | 黑焰邊境、熔岩裂谷、騎士殘骸、深淵火元素 | 紅光需控制，戰鬥傷害數字仍要清楚 |

## 賭場定位

賭場應該是表面華麗、底層腐敗的灰色地帶。它不是單純的商店，也不是單純的金幣遊戲，而是一個會流通消息、違禁品、恐懼、希望與荒唐奇蹟的場所。

### 氣味與聲音的基調

- 骨製骰子落桌的脆響。
- 惡魔莊家的低語，像在替玩家心裡最貪婪的念頭配音。
- 突兀的狂笑與暗處微弱的抽泣聲同時存在。
- 濃郁焚香、鐵鏽味、劣質烈酒、舊羊皮紙霉味混在一起。
- 金幣很亮，但桌底的影子更重。

### 故事角色

賭場要讓玩家能成為其中一員，不只是旁觀。

- 小賭客：用小額金幣換籌碼，取得補給或素材。
- 情報買家：用籌碼、特殊物品或勝場換取 BOSS、黑市、任務情報。
- 灰色搬運者：替帳房、黑市或落魄賭徒處理特殊委託。
- 風險追逐者：用更高風險換取圖紙碎片、稀有素材或傳說獎池機會。
- 被盯上的常勝客：贏太多後觸發賭場注意、暗中試探、特殊交易或威脅。

## 賭場玩法模型

現有老虎機、輪盤、骰子可以保留概念，但不能只停留在金幣輸贏。建議把賭場拆成三個可逐步落地的玩法層。

### 1. 骨骰賭局

定位：可控風險的 push-your-luck 玩法。

玩家每輪下注金幣或籌碼，擲出結果後可以選擇收手或加碼。每次加碼提高倍率，也提高被莊家反咬的風險。

可加入的結果：

- 小勝：返還籌碼與少量獎勵。
- 大勝：獲得獎池抽取次數或高階材料。
- 莊家注視：下一輪風險升高，可能觸發特殊事件。
- 骨骰裂響：取得一段賭場見聞、黑市暗號或任務線索。
- 血色敗局：失去下注，並累積失手記錄，可能觸發落魄賭徒或帳房支線。

### 2. 奇物獎池

定位：玩家期待的抽獎與兌換核心。

抽獎不直接使用金幣，而使用籌碼、賭場券、黑市籤或特殊任務票。畫面要清楚顯示目前獎池的稀有度分布，但高稀有物可以用剪影或部分名稱呈現，等玩家解鎖百科或抽中後再完整顯示。

獎池類型：

- 日常獎池：補給、金幣、常見材料、低階圖紙碎片。
- 黑市獎池：稀有素材、特殊情報、戰術技能書、任務道具。
- 章節獎池：跟章節進度綁定，第二章偏情報與灰色交易，第三章偏終局準備。
- 傳說獎池：章節門檻、次數限制或高成本，不允許無限制刷出終局裝備。

### 3. 帳房與情報

定位：把賭場接入主線、支線與世界變化。

帳房瑪洛不只是任務 NPC，他應該成為賭場規則的翻譯者。玩家可以透過他處理假勝率、黑錢流向、救濟基金、黑市供貨與特殊賭局。

可支援的行為：

- 用籌碼換情報。
- 用特殊道具換獎池入場券。
- 用勝場或虧損記錄解鎖對話。
- 用第三章避難狀態改變賭場貨架。
- 完成賭場支線後，讓城鎮動態出現救濟、腐敗、暗流或傳聞變化。

## 獎勵經濟

金幣目前不夠稀缺，所以賭場不能只回饋金幣。它應該用「金幣換籌碼，籌碼換機會，機會換資源與故事」的方式建立價值。

### 推薦獎勵類型

- 金幣與籌碼。
- 藥水、補給、撤退相關道具。
- 一般材料與稀有材料。
- 高階鍛造材料與詞條重鑄材料。
- 圖紙碎片或副本主題圖紙的提前取得機會。
- 戰術技能書。
- 黑市情報、BOSS 線索、特殊地點傳聞。
- 賭場限定裝備。
- 傳說裝備或傳說材料。
- 支線任務道具，例如帳冊、假骰、血色籤、救濟券。

### 建議掉落權重

| 稀有層 | 權重 | 內容方向 | 限制 |
| --- | --- | --- | --- |
| 常見 | 55% 到 65% | 籌碼、金幣返還、藥水、低階材料 | 讓玩家不會覺得每次都空手 |
| 優良 | 20% 到 25% | 稀有材料、賭場券、見聞片段、低階圖紙碎片 | 可穩定堆進度 |
| 稀有 | 8% 到 12% | 高階材料、戰術技能書、情報、章節材料 | 需要章節門檻 |
| 史詩 | 2% 到 4% | 賭場限定裝備、特殊任務道具、黑市大情報 | 需限量或冷卻 |
| 傳說 | 0.5% 到 1% | 傳說裝備、終局級材料、特殊收藏 | 需章節鎖、保底或一次性規則 |

### 防止破壞平衡

- 傳說獎池不得在第一章開放。
- 終局級裝備不能只靠金幣無限抽出。
- 保底可以給稀有材料或圖紙碎片，不一定直接給傳說裝備。
- 高階獎品可以限量，抽完後改為補貨倒數或章節刷新。
- 賭場限定裝備要有鮮明風味，但不能全面碾壓副本與 BOSS 掉落。

## 賭場 UI 方向

不要做成滿版陌生介面。它應維持目前專案的資訊密度，但把功能收進更像「對話交易」的流程。

推薦分區：

- 賭桌：骨骰、輪盤、老虎機等主要賭局。
- 奇物獎池：抽獎、兌換、傳說剪影。
- 帳房：任務、情報、特殊交易、籌碼兌換。
- 記錄：勝負、淨利、連敗、莊家注意度、已抽獎品。

畫面要求：

- 右側動態欄保留，寫入賭桌聲音、莊家低語、旁人反應與獎池結果。
- 獎品使用共用物品格與稀有度外框。
- hover 使用共用 ItemTooltip，不再出現原生 title。
- 大獎可以有短暫演出，但不能廉價閃爍或干擾點擊。
- 1280x631 下不可需要整頁縱向滾動才能完成一次賭局。

## 賭場故事入口

目前已有兩條賭場委託：第二章假勝率與第三章最後一夜籌碼。後續擴充時可往下列方向接。

- 第二章：黑市與灰燼男爵的金流，玩家發現賭場不是單純詐賭，而是戰爭與避難資源的洗錢點。
- 第二章支線：輸到崩潰的士兵、替人藏籌碼的孩子、買假勝率的貴族僕人。
- 第三章：賭場用籌碼換救濟券，華麗外皮下開始出現末日避難功能。
- 隱藏觸發：連敗、連勝、抽到可疑獎品、持有假骰、拿到帳冊、與瑪洛信任度達標。

## 新增素材方向

### 場景

- `scene.casino_hall`：金色燈火、紅絨桌、暗處人群、帳房桌、黑市門縫。華麗但腐敗。
- `scene.casino_game_table`：骨骰、舊羊皮紙、鐵鏽色桌毯、籌碼、蠟燭、酒痕。中央要乾淨可放互動。
- `scene.casino_prize_wall`：奇物櫃、鎖住的傳說剪影、稀有素材展示、暗金標籤。

### 物件與道具

- `item.bone_dice`：骨製骰子，帶細小裂紋。
- `item.black_market_ticket`：黑市籤，能進入特殊獎池。
- `item.casino_prize_case`：獎品匣，用於大獎演出。
- `item.blood_chip`：血色籌碼，用於高風險賭局。
- `item.relief_voucher`：救濟券，第三章賭場資源轉換用。
- `world.casino_prize_wall`：奇物獎池場景物件。
- `world.casino_whisper_contract`：惡魔莊家低語或特殊契約事件。

### 人物

- `npc.marlow`：帳房瑪洛，保留現有定位。
- `npc.demon_dealer`：惡魔莊家，不一定一開始出現，可作為高風險賭局或第三章暗線。
- `npc.ruined_gambler`：落魄賭徒，用於連敗、救濟或支線。
- `npc.casino_guard`：維持秩序的守衛，用於贏太多後的壓力事件。

## 實作階段建議

1. 先驗收副本是否完全使用共用戰鬥 UI 與結算流程，避免背景圖完成後才發現體驗斷裂。
2. 建立賭場獎池資料結構：籌碼、獎池、稀有度、章節門檻、限量、保底。
3. 重構賭場 UI，維持對話交易感與右側動態欄。
4. 接入瑪洛、黑市、賭場任務、連勝/連敗/莊家注意度。
5. 生成並替換副本背景與賭場素材。
6. 用 1280x631 驗收大廳、市集、賭場、五個副本、戰鬥、結算、手札。

## 已落地紀錄

- 賭場已新增籌碼錢包與帳房兌換：金幣可以換成籌碼，籌碼用於奇物獎池，不再直接用金幣抽獎。
- 三個獎池已建立：日常奇物櫃、黑市奇物櫃、最後燈火獎池。獎池支援章節門檻、任務旗標、限量、保底與稀有度顯示。
- 骨骰、老虎機、輪盤仍保留，但勝利與連敗會額外產生籌碼，讓賭場回饋不只等於金幣。
- 右側動態與賭場記錄已接入賭場頁，並用 1280x631 修正帳房、獎池與統計欄位版型。
- 尚未落地：正式賭場背景、桌面素材、獎池牆素材、惡魔莊家與高風險賭局深層事件。

## 暫不做的事

- 不把賭場做成純粹大型 minigame 平台，避免偏離 RPG 核心。
- 不讓金幣直接無限抽傳說裝備。
- 不新增與現有鍛造平行的另一套鍛造入口。
- 不讓副本使用獨立戰鬥 UI 或獨立物品顯示邏輯。
